    使用说明

    支持的书写方式

    • 一次函数：2x+1、y=-3x+2、kx+b
    • 二次函数：x^2-3x+2、x²、-x^2+4x、a*x^2+b*x+c
    • 反比例函数：1/x、-2/x、6/(x-1)、k/x
    • 指数 / 对数：2^x、e^x、ln(x)、lg(x)、log2(x)
    • 三角 / 反三角：sin(x)、2sin(2x+pi/3)、tan(x)、asin(x)
    • 根式 / 绝对值 / 取整：sqrt(x)、x^(1/3)、|x-1|+2、floor(x)

    不必写 y=；2x、x(x+1) 这类省略乘号的写法会被自动识别； π、×、÷、² 等全角/特殊符号也可以直接输入。

    参数函数

    表达式里除了 x 以外的字母（如 a、b、k）都会自动变成参数， 下方出现滑块，拖动即可实时观察图像变化。例如输入 a*x^2+b*x+c 或 kx+b。

    画布操作

    • 滚轮：以鼠标位置为中心缩放
    • 拖动：平移坐标系
    • 双击：恢复默认视图（-10 ~ 10）
    • 移动鼠标：显示十字准线与各函数在该 x 处的取值
    • 触屏：单指拖动平移，双指捏合缩放
    • 键盘：方向键平移，+ / - 缩放，R 复位

    切线、积分与导数曲线

    工具栏点 切线 后，点击曲线上任意一点即可画出该点切线并显示斜率； 点 ∫面积 后先点起点再点终点，自动为曲线与 x 轴围成的区域着色并计算定积分 （区间内有奇点时会给出提示）。函数卡片上的 f′ 按钮可叠加导数曲线（虚线）。 工具栏的 💾保存 / 📂打开 可把当前全部函数与视野存成文件，或从文件恢复， 方便换设备继续使用；不保存时状态也会自动保存在本机，下次打开自动恢复。

    导出图片

    工具栏 ⬇ 打开导出对话框：可选“当前尺寸 / 2× / 1080p / 1440p / 4K / 5K / 8K / 1 亿像素”， 也可直接输入任意宽高（只限制总像素约 1.08 亿，单边不设固定上限，实际受浏览器画布上限约束）。导出会按所选分辨率 重新绘制而不是放大截图，文字和线条保持清晰；长宽比与画布不同时， 画面按目标比例拉伸，保证完整视野。

    触屏与光标模式

    手机 / 平板打开时会自动进入光标模式（工具栏 光标 按钮高亮）：手指按住画布拖动， 十字准线会自动浮在手指上方实时跟随，不会被手指遮挡，像鼠标悬停一样连续读数； 抬手后准线停在原地，点按其他位置可移动光标。拖动仍是平移，双指捏合仍是缩放。 桌面浏览器默认关闭（移动鼠标即可读数），需要时也可点 光标 按钮手动开关。

    关于对数记号的说明

    按照国内教材习惯：lg(x) 表示常用对数（以 10 为底），ln(x) 表示自然对数， log(x) 等同于以 10 为底，log(x, b) 表示以 b 为底。

    后端在做什么

    函数的解析、类型识别（一次 / 二次 / 反比例 / 指数 / 对数 …）、零点、顶点、渐近线、单调区间等 全部由 Python（SymPy）计算；前端只负责把结果画出来。坐标轴网格、曲线平滑采样与不连续点断开 也由后端的自适应采样算法完成。
