# OrthoPlot · 正绘（函数图像绘制器）

一个用 **HTML + Python** 实现的函数图像网站：输入任意表达式，后端用 SymPy 做符号分析，前端用 Canvas 实时绘制图像，
并把函数的类型、定义域、零点、顶点、渐近线、单调区间、导数等性质一并算出来。

前后端分工明确：

| 部分 | 技术 | 负责的事 |
| --- | --- | --- |
| 后端 | Python 3 + Flask + SymPy | 解析表达式、识别函数类型、求零点/顶点/渐近线/极值/单调区间、自适应采样出折线数据 |
| 前端 | 原生 HTML / CSS / JavaScript（无第三方库） | 输入与函数管理、Canvas 绘制、缩放平移、十字准线读数、数据表、公式渲染、导出 PNG（可选分辨率） |

## 二、能画什么

在左侧输入框里写表达式（**不用写 `y=`**，回车即可绘制）：

| 类型 | 输入示例 |
| --- | --- |
| 一次函数 / 正比例 | `2x+1`、`-3x+2`、`3x`、`kx+b` |
| 二次函数 | `x^2-3x+2`、`x²`、`-x^2+4x-1`、`a*x^2+b*x+c` |
| 反比例函数 | `1/x`、`-2/x`、`6/(x-1)`、`k/x` |
| 指数 / 对数 | `2^x`、`e^x`、`(1/2)^x`、`ln(x)`、`lg(x)`、`log2(x)`、`log(x,3)` |
| 三角 / 反三角 | `sin(x)`、`2sin(2x+pi/3)`、`cos(x)`、`tan(x)`、`asin(x)` |
| 幂函数 / 根式 | `x^3`、`sqrt(x)`、`x^(1/3)`、`x^(-2)` |
| 绝对值 / 取整 / 分段 | `|x-1|+2`、`floor(x)`、`sign(x)` |
| 复合与任意组合 | `x*sin(1/x)`、`abs(x)+sin(x)`、`(x^2-1)/(x-1)`、`1/(x^2-1)` |

书写上的贴心处理：

* 省略乘号：`2x`、`3sin(2x)`、`x(x+1)` 都能识别；
* 紧凑写法：`sinx`、`2sinx+1`、`lnx`、`sqrtx` 会自动补上括号；
* 全角/特殊符号：`²³`、`π`、`×`、`÷`、`−`、`（）`、`√`、`|x|` 直接输入即可；
* 对数按国内教材习惯：`lg` 是以 10 为底，`ln` 是自然对数，`log(x)` 等价于 `lg(x)`，`log(x,b)` 是以 b 为底。

**参数函数**：表达式里除 `x` 以外的字母（`a`、`b`、`k`、`m`…）会自动变成参数，函数卡片下方出现滑块，
拖动滑块图像和性质分析会实时刷新，适合讲 `y=kx+b` 中 k、b 的作用这类内容。

## 三、界面上能做什么

* **函数列表**：可同时绘制多条曲线，支持隐藏/显示、换颜色、删除、清空。
* **性质分析**（点函数卡片上的 ⓘ）：函数类型、基本性质（开口方向、顶点、最值、判别式、斜率…）、
  定义域与奇偶性、零点、单调区间、**极值点、拐点**、导数表达式。画布上会同步标出关键点与渐近线。
* **导数曲线**：函数卡片上的 `f′` 按钮一键叠加 y′ = f′(x) 虚线曲线，缩放平移全程跟随。
* **切线工具**：激活后点击曲线上任意一点，画出该点切线并显示斜率 k。
* **定积分**：激活后先点起点再点终点，为曲线与 x 轴围成的区域着色并计算定积分
  （辛普森法；区间内有奇点时会给出提示）。
* **画布交互**：滚轮以光标为中心缩放、拖动平移、双击复位；鼠标移动显示十字准线与各条曲线在该 x 处的取值；
  触屏支持单指平移、双指捏合；键盘 `←↑↓→` 平移、`+`/`-` 缩放、`R` 复位。
* **工具栏**：放大/缩小/复位、网格开关、渐近线开关、两两交点开关、切线、∫面积、数据表（整数点的函数值）、全屏、导出 PNG。
  导出时可选分辨率（当前尺寸 / 2× / 1080p / 1440p / 4K / 5K / 8K / 1 亿像素，或自定义宽高；
  只限制总像素约 1.08 亿、单边不设固定上限，实际受浏览器画布上限约束；手机端 1 亿像素导出受内存限制），
  按所选分辨率重新绘制而非放大截图，文字与线条保持清晰。
* **函数预设库**：按类别分组的常见函数，点击即绘制。
* **自动保存**：函数列表与视野自动保存在本机，下次打开自动恢复。
* **光标模式**：触屏设备自动开启，点按画布任意位置即可读取各曲线在该点的数值，
  工具栏"光标"按钮可随时开关（桌面默认关闭，移动鼠标即可读数）。
* **保存 / 打开文件**：右上角 💾保存 把当前全部函数（含参数、颜色、f′ 状态）与视野存成
  `.json` 文件（进入浏览器下载目录），📂打开 可随时恢复，也方便传给别的设备继续用。
* **夜间模式**：右上角切换，画布配色同步变化。

## 五、后端接口

| 接口 | 说明 |
| --- | --- |
| `GET /` | 页面 |
| `GET /api/health` | 健康检查 |
| `GET /api/presets` | 预设函数库 |
| `POST /api/analyze` | 解析并分析一个函数：类型、性质、零点、渐近线、单调区间、极值、拐点、导数 |
| `POST /api/plot` | 批量采样曲线（绘图数据），可选 `derivative: true` 同时采样导数曲线，可选返回整数点数据表 |
| `POST /api/intersections` | 求两个函数在给定区间内的交点 |
| `POST /api/tangent` | 求函数在 x₀ 处的切线（切点 + 斜率） |
| `POST /api/integral` | 数值计算定积分（辛普森法，区间含奇点时报错） |

示例：

```bash
curl -X POST http://127.0.0.1:8000/api/analyze \
     -H 'Content-Type: application/json' \
     -d '{"expr":"6/(x-1)","xmin":-20,"xmax":20}'
```

```json

  "properties": [
    {"label": "比例系数 k", "value": "6"},
    {"label": "对称中心", "value": "(1, 0)"},
```

## 六、实现要点

* **安全解析**：表达式通过 SymPy 的 `parse_expr` 解析，命名空间里屏蔽了 `__builtins__`，
  只有白名单函数（sin/cos/ln/log/sqrt/abs/floor…）与常数可用，不存在执行任意代码的风险。
* **自适应采样**：先均匀取点，再按曲率递归细分；符号法求出分母零点，数值法探测极点与定义域边界，
  在这些位置把曲线断开，因此 `1/x`、`tan(x)`、`ln(x)` 不会被画成一条错误的连线。
* **类型识别**：按多项式次数、是否分式、是否含指数/对数/三角/根式/绝对值/取整等逐层判断，
  含参数时先把参数代入再判断，保证 `kx+b`、`a*x^2+b*x+c` 也能正确归类。
* **数值稳定性**：求值器依次尝试 `math` → `mpmath` → SymPy 三种后端，避免 `1/(x-1)` 这类
  在探测点恰好除零的表达式退化成极慢的符号求值；渐近线判定会在多个大数量级取样，避免把
  `x+sin(x)` 误判成有斜渐近线。
* **前端性能**：平移/缩放只请求 `/api/plot`（快速采样），符号分析只在表达式或参数变化时请求，
  并且请求范围比可视范围大 40%，拖动时不会出现空白边缘。

## 七、常见问题

**Q：端口被占用？**
换一个端口启动，例如 `python3 app.py --port 8080`。

**Q：为什么 `lg(x)`、`log2(x)` 都能用，但 `log(x)` 不是以 e 为底？**
按国内中学教材习惯，`log(x)` 默认以 10 为底；需要其它底数请写 `log(x, b)` 或 `log(x, 2)`。

**Q：输入后曲线没出现？**
函数卡片上会显示红色错误提示（例如括号不配对、函数名不认识、定义域为空）。后端没启动时页面也会提示。

**Q：能画 `x^2+y^2=1` 这种隐函数吗？**
不能。本网站只支持 `y = f(x)` 形式的显函数。
